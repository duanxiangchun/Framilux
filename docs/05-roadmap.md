## 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 部分模型许可证不明 | 无法商用 | manifest 标记 + CI 门禁；优先替换为 Apache/MIT 权重 |
| 规则权重靠拍脑袋 | 建议"有道理但不好用" | M5 的校准工具链前置到 M3 就开始收集样本 |
| 端侧多模型内存/线程冲突 | 卡顿、崩溃 | 单一推理队列 + 缓冲池；M2 就压测 |
| 显著性模型在特定场景失效 | 主体找错 | 降级到"人脸 ∪ 最大前景块"，并允许用户点选主体（可选功能） |
| 低端机跑不动 | 体验塌方 | 分级降档到 L4（纯 IMU + 静态辅助线）仍保证可用 |
| 与商业 App 同质化 | 无差异化 | 主打**光影与姿态**这两块（同类产品普遍缺失）+ 完全离线的可信度 |

## 下一步（本次交付后的第一个动作）

从 **M1** 开始：在 `web-prototype/` 初始化 Vite 工程，先跑通"取流 → 人脸/姿态 → R1/R2/R3/R4 打分 → 叠加层"这条最短路径，把规则权重调出直觉。
