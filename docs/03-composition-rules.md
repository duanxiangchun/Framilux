# 03 · 构图 / 光影 / 姿态规则设计

这是项目的**灵魂文档**：感知层给数据，这里决定"什么算好、怎么改"。

## 1. 特征约定

- 所有坐标**归一化到 [0,1]**，原点左上，x 为宽方向，y 为高方向
- 距离计算前先乘宽高比，避免"横向 0.1"和"纵向 0.1"被当成同样的距离
- 主体（subject）= 由显著性图加权的重心区域 ∪ 人脸框 ∪ 人体框，取面积与显著度最大的那个

## 2. 规则清单

每条规则输出 `f ∈ [0,1]`（1 = 最理想）与可选的局部建议文案。最终得分由场景权重组装。

### R1 三分点对齐 `thirds`

```
p = 四个三分交点 (1/3,1/3) (2/3,1/3) (1/3,2/3) (2/3,2/3)
d = min_i || (c_subj - p_i) ⊙ (W,H) || / diag(W,H)
f = clamp(1 - d / 0.18, 0, 1)
```

中心构图是有效的替代解：若 `|c_subj - (0.5,0.5)| < 0.06`，则 `f = max(f, 0.85)`（场景画像为"对称/建筑"时该豁免更强）。

### R2 水平矫正 `horizon`

```
tilt = 融合(IMU roll, 地平线检测角度)   // 有地平线时以视觉为准，否则用 IMU
f = clamp(1 - |tilt| / 6°, 0, 1)
|tilt| > 3° → 强制高优先级提示（含方向：顺时针/逆时针 + 度数）
```

### R3 主体占比 `subjectRatio`

```
r = area(subject) / (W·H)
f = exp( -((r - r*) / σ)² )
人像: r* = 0.18, σ = 0.10     风景: r* = 0.06, σ = 0.05
建筑: r* = 0.14, σ = 0.09     美食/静物: r* = 0.30, σ = 0.12
```

`r` 偏离超过 1σ 时提示"靠近一点 / 退后一点"。

### R4 头顶留白 `headroom`

```
h = top(face)        // 人脸框上边到画面顶部的距离
理想区间 [0.05, 0.12]；h < 0.02 → 切头顶（重罚）
f = 1                          if 0.05 ≤ h ≤ 0.12
f = 1 - (0.05 - h)/0.05        if h < 0.05
f = clamp(1 - (h - 0.12)/0.25, 0, 1)  if h > 0.12
```

### R5 朝向留白 `leadRoom`

由姿态关键点或人脸 yaw 估计人物朝向 `dir ∈ {left, right, front}`：

```
前向空间 front = 1 - right(face)   （朝右时）
后向空间 back  = left(face)
f = clamp((front - back) / 0.25, 0, 1)      // 前向留白应显著多于后向
front < 0.08 → 提示"往人物面向的一侧挪一点"
```

朝向为正面时该规则权重降为 0.2（正脸留白规则不适用）。

### R6 视觉平衡 `balance`

用显著图算视觉质量矩：

```
g = 显著图质心
力矩 imbalance = || g - (0.5,0.5) ⊙ (W,H) || / diag   // 只惩罚"空的一侧过空"
f = clamp(1 - imbalance / 0.22, 0, 1)
```

注意：与 R1 不冲突——R1 允许主体偏心，R6 惩罚的是**重心偏离但没有配重**（例如人全挤在左边、右边全空）。

### R7 引导线 `leadingLines`

```
线段聚类 → 主方向 θ 与消失点 v（至少 3 条线近似共点才成立）
f = 1 - clamp( d(c_subj, 消失点方向走廊) / 0.25, 0, 1 )
没有可信消失点时该规则权重归 0（不要硬凑）
```

### R8 对称 `symmetry`

竖直镜像相似度 `s ∈ [0,1]`：`f = s`，并检查主体中心与对称轴的偏移 `< 0.04`。仅在建筑/对称场景启用。

### R9 光位 `lighting`（本项目区别于同类产品的关键）

输入：人脸区域分区亮度、背景亮度、DSINE 法线图、Slow 通路。

```
逆光   : mean(背景) / mean(人脸) > 1.6  → 重罚，提示"转身或开 HDR/补光"
侧光   : |mean(左脸) - mean(右脸)| / mean(人脸) ∈ [0.12, 0.35] → 加分（立体感）
顶光   : 额头亮 + 眼下阴影深（分区亮度差 > 0.25） → 提示"稍抬头 / 换位置"
顺光平光: 左右差 < 0.08 且背景不亮 → 中性（人像可接受，风光偏平）
黄金时刻: 整体色温偏暖 + 低角度侧光 → 加分
```

`f_lighting` 由上面几条合成，具体映射见 §3 权重表的 lightBonus / lightPenalty 两列。

### R10 曝光质量 `exposure`

```
人脸平均亮度 L（线性 0–1，gamma 校正后）
f = exp( -((L - 0.52) / 0.18)² )
```

### R11 动态范围 `clipping`

```
溢出比例 = 像素 > 0.98 的占比；死黑比例 = 像素 < 0.02 的占比
f = 1 - clamp(溢出/0.03, 0, 1)·0.6 - clamp(死黑/0.08, 0, 1)·0.4
```

### R12 姿态 `pose`（P1）

由 RTMPose 的 17 关键点算：

| 子项 | 判据 | 建议 |
|---|---|---|
| 挡脸 | 手腕关键点落入人脸框 | "把手放低一点" |
| 肩线倾斜 | 双肩连线与水平夹角 > 12° | "站直 / 靠一下" |
| 躯干占比 | 躯干高度 / 画面高 < 0.25 | "靠近一点" |
| 关节打开度 | 肘、膝夹角接近 180°（僵直）或 < 60°（蜷缩） | "手臂放松，稍微张开" |
| 模板匹配 | 与姿势模板库的归一化关节角余弦相似度 | "试试这个姿势"（P2） |

模板匹配方法：把关键点按"髋部中心 + 躯干长度"归一化，取左右对称平均后得到姿态向量，与模板库做余弦相似度。**不需要训练**，模板就是若干张参考照的骨架。

## 4. 从分项到总分

```
s01  = Σ(w_i · f_i) / Σ(w_i)
展示 = 1 + 4 · s01^0.8        // 映射到 1.0–5.0
颜色阈值：< 2.5 红 / < 3.5 橙 / < 4.2 黄 / ≥ 4.2 绿（"可以拍了"）
```

分项得分同时保留，用于拍后评审页告诉用户"是哪一项拖了后腿"。

## 5. 引导求解（"该怎么改"）

`GuidanceSolver` 的目标不是打分，而是**输出可执行的动作**：

```
1) 目标主体位置 c*
   取距离当前 c_subj 最近、且方向合理的三分交点；对称场景取画面中心
2) 位移向量 Δ = (c* - c_subj) ⊙ (W, H)          // 归一化画面坐标
3) 动作离散化（避免用户困惑，一次只说一件事）
   |Δ.x| > 0.06 → "向左/向右平移一点"（幅度分 近/远两档）
   |Δ.y| > 0.06 → "手机抬高/放低一点"
   否则 → 位置 OK，转向其它规则
4) 变焦/距离提示：由 R3 的 (r - r*) 与深度估计换算
   r < r* - σ → "靠近一点"；r > r* + σ → "退后一点"
5) 水平：|tilt| > 1° → "顺时针/逆时针微调 N°" + 水平仪
6) 文案优先级（**每帧只出一条主建议**）
   水平 > 逆光/严重曝光 > 位置 > 占比/留白 > 构图风格建议
```

**为什么必须离散化**：用户无法根据"Δ=0.073"做动作。连续量只用于渲染箭头长度与目标虚影框，文字必须是人话。

## 7. 权重怎么校准（关键工程动作）

1. 收集 200–500 张真实场景照片（覆盖 7 类画像），用相机同时记录当时的 PerceptionFrame 特征
2. 请 3–5 人独立排序（或标注 1–5 分），取平均作为标签
3. 在离线脚本里做**网格搜索 / 逻辑回归**拟合权重，目标：与人工排序的 Spearman 相关最大化
4. 用 NIMA 分作为**弱监督**交叉验证（注意 NIMA 偏技术质量与整体美感，与构图不完全一致，只能当参考）
5. 权重迭代必须留版本号，便于回滚与 A/B

这一步不做，规则就是拍脑袋；做了，引导才真的"像摄影师"。
